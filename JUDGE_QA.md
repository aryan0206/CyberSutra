# Judge Q&A

## Is this an NCRP product?

No. It is an independent demo that prepares information for human review.

## Does AI determine what happened?

No. The current MVP does not call AI or perform extraction. Its synthetic demo uses hand-authored facts, while deterministic rules validate and the user confirms. AI is only a future architectural concept.

## Is any evidence sent externally?

Not in the mock prototype. It uses local browser storage only.

## Does the fingerprint prove evidence is genuine?

No. It is a local SHA-256 fingerprint of the processed file bytes. It identifies that exact file for this demo but does not establish authenticity, admissibility, government validation, or pre-upload history.
