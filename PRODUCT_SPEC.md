# Product specification

CyberSutra is a hackathon prototype for preparing a structured, evidence-linked report for online financial cyber fraud.

## Boundary

The product supports evidence intake, extraction, provenance, timeline, contradiction and missing-information review, deterministic readiness, deterministic report generation, and mock submission only. It is not an official government application and never submits a real complaint. All reports are assembled exclusively from authoritative case state, and mock submissions use simulated adapter boundaries with zero outbound network communication.
